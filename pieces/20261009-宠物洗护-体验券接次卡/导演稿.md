# 【mac-director｜导演交付稿】

- 项目 / 系列名：券到卡包｜实体店经营问题拆解
- 本期固定标题（唯一上屏标题）：宠物洗护，体验券怎么接次卡？
- 制作模式：样图验证模式。首验通过前不开展后续批量生图。
- 当前锁定状态：标题和第一镜口播已由用户确认，按原文执行，不擅自润色。

## 全片前置摘要

- **目标商家与认知起点：** 社区宠物洗护店经营者。知道优惠券和次卡能帮助经营，但容易把它们当作同一种促销工具，没有按顾客所处阶段分工。
- **本条唯一核心问题：** 首次洗护的体验优惠、下次到店的理由、持续需求的次卡，应该怎样接续而不混用？
- **观众的学习目标：** 能把三者的业务任务分开，并知道次卡不应在尚未确认持续需求时提前推给每位新客。
- **看完后应记住的一句话：** 体验券负责第一次，下次洗护优惠给顾客再来的理由，次卡承接已经明确的持续需求。
- **核心结论及依据：** “体验券”是业务用途称呼，不是现有优惠券类型表中独立的一种券种；要根据实际优惠内容选择现有券种。优惠券可按创建时设定的方式公开领取或私密发放；次卡仅私密发放。依据：本仓库 spec/功能真值.json 的 lines 优惠券、次卡字段。这里不承诺发券必然带来回访或复购。
- **本条推理链（供导演审核，不是默认上屏图解）：** 第一次体验要有清楚的优惠 → 服务结束后另给一个下次到店理由 → 顾客真的再来并体现持续需求 → 再介绍按次核销的洗护次卡。
- **关键术语及平实解释：**
  - 体验券：给首次到店场景使用的优惠券，是用途叫法，不是额外新增的券种。
  - 下次洗护优惠：单独设置、用于下一次洗护的优惠券；使用条件、适用服务和有效期应按商家真实方案设置。
  - 次卡：按次核销的卡类产品，适合承接已经明确的持续服务需求；不是把几张优惠券随意叫成次卡。
- **本期组合及分工：** 首次体验优惠券 → 下一次洗护优惠券 → 按次核销的洗护次卡。它们是连续但不同的经营动作，不是自动转化链。
- **采用理由、成立条件与边界：** 每一步对应顾客不同阶段，概念容易通过同一位顾客与同一只宠物的连续故事呈现。商家须按真实提供的洗护服务配置优惠条件；不能承诺顾客一定回来，也不能把首次消费当作稳定需求的证据。
- **产品事实、行业判断、经营数字的来源与核验状态：** 产品规则只使用已读取的 spec/功能真值.json；本轮没有读取官网页面、业务 MCP 或 applet 源码，因此不声称本轮已完成这些来源的独立核验。未使用经营成效数字。
- **来源冲突、尚未核实或本条不能据此下结论的事项：** 没有证据支持“发体验券会保证复购”“次卡越早卖越好”或任何提升比例；本片不作此类承诺。具体服务价格、优惠力度和券规则由商家按真实服务决定，本片不编造。
- **视觉策略：** 前三张连续样图以同一顾客、同一只比熊和同一门店完成进店、洗护、离店的动作连续性验证；首轮样图不加画内文案、标题、品牌或流程图。后续镜头如需概念卡，只使用导演明确指定的短文案，并在制作层逐字验收。
