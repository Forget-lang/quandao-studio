# 券到卡包短视频工作流启动提示词

> 本文件供用户在新会话中复制使用。
>
> 它是工作流启动入口，不替代仓库中的正式规则。正式要求以 `AGENTS.md`、`mac-director/SKILL.md`、`quandao-video/SKILL.md` 及相关 `spec` 文件为准。

```text
你现在要在券到卡包正式短视频产线 quandao-studio 中执行本轮任务。

仓库：https://github.com/Forget-lang/quandao-studio
请以仓库当前 main 分支文件为唯一依据，不依赖旧会话记忆。

开始前：
1. 读取 AGENTS.md，确认当前工作流入口。
2. 根据任务阶段读取对应技能：
   - 选题、经营逻辑、口播、导演稿、分镜：读取 mac-director/SKILL.md
   - 生图、TTS、字幕、工程、渲染、成片验收：读取 quandao-video/SKILL.md
3. 根据题目读取需要的 spec 与 reference 文件，产品事实不能凭常识补充。
4. 明确当前阶段（策划、导演、制作、验收或文档维护），确认实际可用工具和能力。

执行原则：
- 口播负责讲清问题、原因、机制、条件和结论。
- 画面负责呈现场景、人物行为和关键关系。
- 辅助信息负责补足理解缺口，不机械重复口播，也不堆砌信息。
- 内容从行业商家的真实问题出发，讲清为什么值得关注、问题背后的逻辑、解决方式，以及券到卡包能力如何自然承接。
- 不把视频写成功能清单，也不强行制作操作教程；重点是让商家理解问题、理解方法，并知道产品可以帮助实现。
- 不虚构功能、效果、数据或经营结果。
- 遵守现有视觉规范、品牌规则、验收流程和历史作品冻结规则。

执行过程中：
- 区分“已计划”“已执行”“已验证”。
- 没有实际读取文件、运行命令或检查结果时，不得声称已完成。
- 修改规则或脚本时保持单一规则来源，并执行对应检查。

本轮任务：
（在此填写具体任务）
```
